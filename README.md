# 영화 「더 문」 · 과학 윤리 수행평가

원본 7장을 배경으로 사용하는 모바일 반응형 수행평가입니다.

- 학교·학년·반·번호·이름 필수 검증
- 문항별 서술·선택·비교표, 확대 입력, 자동 임시저장
- Google Apps Script를 통한 제출 및 같은 브라우저에서 재수정·재제출
- 서버의 접수번호 응답을 확인한 경우에만 외부 제출 완료 표시

## 교사용 스프레드시트
첫 번째 탭 ‘교사용 학생 답안’에서 B2 반, B3 학생을 선택하면 답안이 표시됩니다. 반을 변경한 뒤에는 학생을 다시 선택하세요.
‘채점표’의 문항1~6에 각각 0~5점을 입력합니다. 합계는 자동 계산됩니다. 피드백과 최근 제출 상태도 확인할 수 있습니다. 재제출 시 기존 점수는 보존하고 ‘수정됨 · 재채점 확인’을 표시합니다.
‘제출 원본’은 접수번호별 최신 답안을 저장합니다. 최초 제출 시각은 보존하고 최근 수정 시각은 갱신합니다. ‘선택 목록’은 숨김 보조 탭입니다.

## 파일
- index.html / style.css / app.js: 학생용 웹사이트
- assets/1.png~7.png: 원본 이미지 (1.png는 업로드 파일 1(2).png와 동일)
- config.js: Apps Script 웹 앱 주소
- Code.gs: 배포한 서버 코드 사본

config.js의 endpoint가 빈 값이면 로컬 제출 시뮬레이션입니다. endpoint가 설정되면 실제 제출 모드입니다. 서버는 JSON 본문을 받아 {ok:true,receiptId,updatedAt,revised}를 응답합니다. 통신 실패를 제출 완료로 처리하지 않습니다.

학생의 수정 확인값은 해당 브라우저에 보관하고 서버에는 SHA-256 해시만 저장합니다. 브라우저 저장소를 지우거나 다른 기기를 사용하면 기존 제출본을 직접 수정할 수 없습니다. 학생 정보만으로 타인의 답안을 불러오는 공개 API는 제공하지 않습니다. 답안 내려받기는 보관용이며 자동 가져오기를 제공하지 않습니다.

학생 답안은 GitHub 저장소에 포함되지 않습니다. 스프레드시트 공유 범위는 소유자가 설정한 상태를 유지합니다. 공개 제출 주소이므로 수업 운영에 맞는 추가 접근 제한이 필요하다면 교사 계정에서 설정하세요.
